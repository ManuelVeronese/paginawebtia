# KMart Marketing - Landing Page

Esta es una página web moderna, profesional y totalmente responsiva desarrollada para [Nombre de la tía/Negocio]. El objetivo del proyecto fue crear una presencia digital sólida que permitiera mostrar [productos/servicios] de manera elegante y funcional.

## 🚀 Características

- **Diseño Responsivo:** Adaptado para dispositivos móviles, tablets y escritorio.
- **Animaciones Modernas:** Implementación de efectos visuales al hacer scroll para una mejor experiencia de usuario.
- **Arquitectura de Layout:** Uso avanzado de CSS Grid y Flexbox para una estructura limpia y mantenible.
- **Optimización de Carga:** Imágenes y recursos optimizados para un rendimiento eficiente.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.
- **CSS3:** Estilos personalizados, variables de CSS, Flexbox y CSS Grid.
- **JavaScript (Vanilla):** Lógica para la interacción de la navegación móvil.
- **ScrollReveal.js:** Biblioteca para animaciones de entrada al desplazar la página.
- **Google Fonts:** Tipografía profesional seleccionada para mejorar la legibilidad.
